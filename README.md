# هوشمند حساب (Houshmand Hesab) 🇮🇷

حسابدار شخصی هوشمند اندروید — کاملاً آفلاین + تحلیلگر مالی هوش مصنوعی (Cloudflare Workers AI رایگان)

![Platform](https://img.shields.io/badge/Android-SDK%2026%2B-34D399) ![Kotlin](https://img.shields.io/badge/Kotlin-2.0-60A5FA) ![Compose](https://img.shields.io/badge/Jetpack%20Compose-Material%203-A78BFA)

## امکانات

### 💳 مدیریت مالی
- ثبت درآمد / هزینه / انتقال بین حساب‌ها
- حساب‌های چندگانه (نقد، بانک، کیف پول) با موجودی جداگانه
- دسته‌بندی دلخواه با ۲۰+ آیکون و ۱۰ رنگ
- تراکنش‌های تکرارشونده (اجاره، حقوق، اشتراک) — ثبت خودکار
- یادداشت + پیوست عکس رسید برای هر تراکنش
- جستجو و فیلتر پیشرفته (نوع، دسته، ماه شمسی)

### 📊 گزارش و تحلیل
- داشبورد: موجودی کل + جریان نقدی + نمودار ۷ روز اخیر
- نمودار دایره‌ای دسته‌های هزینه + مقایسه ۶ ماه اخیر
- میانگین خرج روزانه + بزرگ‌ترین هزینه ماه
- گروه‌بندی روزانه تراکنش‌ها با تقویم شمسی

### 🎯 بودجه و هدف
- بودجه ماهانه هر دسته + نوار پیشرفت رنگی (هشدار ۷۰٪ و ۱۰۰٪)
- اهداف پس‌انداز با مهلت و درصد پیشرفت
- نوتیفیکیشن: رد شدن از بودجه + یادآوری سررسید بدهی

### 🏦 بدهی و قسط
- «من بدهکارم» / «بدهکار منِ»
- سررسید + وضعیت تسویه + تعداد اقساط

### 🤖 حسابدار هوشمند (AI)
- چت با تحلیلگر مالی متصل به **Cloudflare Workers AI** (رایگان)
- تحلیل خرج ماه، پیشنهاد پس‌انداز، تشخیص هدررفت پول
- پیشنهاد خودکار دسته برای تراکنش از روی یادداشت
- داده‌های واقعی تراکنش‌ها به‌عنوان زمینه به AI داده می‌شود

### 🔒 امنیت و شخصی‌سازی
- قفل اپ با PIN + اثر انگشت (Biometric)
- تم تیره / روشن / سیستمی + Material You
- فارسی (RTL) + انگلیسی — اعداد فارسی/انگلیسی
- تقویم کاملاً **شمسی** (جلالی)
- واحد پول قابل تنظیم
- خروجی CSV / پشتیبان JSON / بازیابی کامل
- همه داده‌ها فقط روی گوشی خودت (Room + DataStore)

## راه‌اندازی Cloudflare AI (رایگان)

1. در [dash.cloudflare.com](https://dash.cloudflare.com) اکانت رایگان بساز
2. از صفحه Home مقدار **Account ID** را کپی کن
3. از **My Profile → API Tokens → Create Token** یک توکن با دسترسی `Workers AI` بساز
4. در اپ: تنظیمات → هوش مصنوعی → هر دو مقدار را وارد کن و مدل را انتخاب کن (پیش‌فرض: Llama 3.1)

> سهمیه رایگان: ۱۰٬۰۰۰ Neuron در روز — برای استفاده شخصی کاملاً کافی است.

## بیلد با GitHub Actions

1. این ریپو را push کن
2. تب **Actions** → workflow «Build APK» خودکار اجرا می‌شود
3. بعد از ~۱۰ دقیقه، در artefact همین صفحه، APK آماده دانلود است (debug + release)
4. برای Release با تگ: `git tag v1.0 && git push --tags`

### بیلد محلی
```bash
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

## تکنولوژی‌ها

| لایه | ابزار |
|------|-------|
| UI | Kotlin + Jetpack Compose + Material 3 |
| معماری | MVVM + Repository + Hilt DI |
| دیتابیس | Room + DataStore |
| شبکه | Retrofit + Gson |
| AI | Cloudflare Workers AI REST API |
| پس‌زمینه | WorkManager + Hilt Worker |
| فونت | Vazirmatn (رایگان و متن‌باز) |

## ساختار پروژه

```

├── ai/          ← Cloudflare AI + حسابدار هوشمند
├── data/
│   ├── db/      ← Entity / DAO / Room
│   ├── prefs/   ← DataStore تنظیمات
│   └── repo/    ← Repository مرکزی + بکاپ/بازیابی
├── di/          ← ماژول‌های Hilt
├── ui/
│   ├── components/  ← نمودار، تقویم شمسی، کارت‌ها
│   ├── navigation/  ← NavGraph
│   ├── screens/     ← ۱۲ صفحه
│   └── theme/       ← Material 3 + فونت وزیرمتن
```
